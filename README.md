# 🎮 CodeQuest

**Геймифицированное локальное приложение для обучения фулл-стек разработке.**
Всё обучение — это игра: проходи уровни, набирай опыт, держи стрик. План — путь от полного новичка до уверенного **Junior с заявкой на Middle за 3 месяца**.

Вдохновлено [Coddy.tech](https://coddy.tech), но полностью локальное: весь код запускается прямо в браузере, прогресс хранится в `localStorage`, никакого сервера не нужно.

---

## ✨ Что внутри

- **С абсолютного нуля до Junior.** 13 модулей-«миров» по 3 месяцам: HTML → CSS → JavaScript → TypeScript → асинхронность → фронтенд → Node/Express → SQL → REST → Git → финальный проект.
- **Четыре типа шагов в уроке:**
  - 📖 **Теория** — объяснение с примерами кода и врезками.
  - ❓ **Квиз** — вопрос с вариантами, мгновенная проверка.
  - ⌨️ **Код-челлендж** — пишешь функцию, автотесты проверяют её как на LeetCode.
  - 🎨 **Вёрстка** — пишешь HTML/CSS с **живым предпросмотром** (как Vue SFC Playground), проверки идут по DOM и стилям.
- **Редактор CodeMirror 6:** подсветка синтаксиса, автодополнение, автозакрытие тегов и скобок, подсветка пар, номера строк.
- **Живой запуск кода.** JS/TS исполняется в изолированном **Web Worker** (без доступа к DOM, поддержка async/await, таймаут 3 с). HTML/CSS рендерится в песочнице-iframe.
- **Маскот «Байт» 🤖** — бот-проводник: встречает, подсказывает, радуется успехам.
- **Геймификация:** XP, уровни с прогрессивной кривой, ранги (Новичок → Junior → Middle), стрики 🔥, бейджи, всплывающие награды.
- **Прогресс сохраняется** между сессиями. Уроки открываются последовательно.
- **Премиум тёмная тема** (плюс светлая), офлайн-шрифты, интерфейс на русском (`vue-i18n` готов к английскому).

## ➕ Как добавить урок

Контент — это **данные**, а не код. Чтобы добавить урок, отредактируй файл модуля в `src/content/modules/`:

```ts
{
  id: 'l6-objects',
  title: 'Объекты',
  subtitle: 'Ключ-значение',
  xp: 50,
  icon: '📦',
  steps: [
    { kind: 'theory', title: '...', blocks: [{ type: 'text', md: '...' }] },
    { kind: 'quiz', question: '...', options: ['...'], answer: 0 },
    {
      kind: 'code',
      title: '...',
      prompt: 'Напиши функцию `getName(user)`...',
      lang: 'js',
      entry: 'getName',                 // имя функции, которую пишет ученик
      starter: 'function getName(user) {\n  \n}',
      tests: [{ name: '...', args: [{ name: 'Аня' }], expected: 'Аня' }],
      solution: 'function getName(user) { return user.name }',
    },
  ],
}
```

Тест `src/content/content.test.ts` автоматически прогоняет каждое `solution` через его же `tests` — если решение не проходит, CI об этом сообщит. Так контент всегда остаётся корректным.

## 🗺️ Программа обучения (3 месяца)

- **Месяц 1 · Основы:** JavaScript (переменные, типы, условия, циклы, массивы), функции высшего порядка (map/filter/reduce), алгоритмы-разминка.
- **Месяц 2 · Стек:** TypeScript, асинхронность (Promise/async/await), фронтенд-компоненты (Vue/React), Node.js + Express.
- **Месяц 3 · Профи:** базы данных и SQL, REST API и архитектура, Git/тесты/деплой, финальный фулл-стек проект в портфолио.

> Модули 1–3 наполнены полностью (играбельны от начала до конца). Модули 4–11 — вводные уроки, задающие каркас; наращиваются тем же форматом данных.

## 🔒 Безопасность песочницы

Код ученика исполняется в отдельном `Web Worker`, у которого нет доступа к DOM и к главному потоку. Главный поток терминирует воркер по таймауту, что защищает от зависаний (бесконечные циклы). Учебный markdown-контент экранируется перед рендером.
